# M0 驗收測試方案（M0_TEST_PLAN.md）

適用：M1 起每次改動後的功能驗收。原則：每條用例有預期結果與證據留存方式；涉及生產數據的用例標註【寫庫】需用測試標記數據。

## 1. 部署一致性（每次發佈後）
| 用例 | 步驟 | 預期 |
|---|---|---|
| T1.1 前端版本標記 | `curl -s https://richapps.pages.dev/amcm/ \| grep -c "law-article-title"` | ≥3（v3.1 特徵存在） |
| T1.2 Worker 版本 | `wrangler deployments list` 最新 version id 與本次部署一致 | ✅ |
| T1.3 本地=線上 | 對比 `public/amcm/index.html` 與線上 HTML 字節大小 | 一致 |
