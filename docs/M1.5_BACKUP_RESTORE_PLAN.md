> 原則：不碰生產庫。D1 免費檔支持建第二個數據庫，恢復演練全部在副本上進行。

1. **建副本庫**：`npx wrangler d1 create amcm-db-restore-test`（獨立 database_id）。
2. **建表**：在新庫執行 `amcm-etl/d1_schema.sql`（表結構與生產一致，含 FTS 觸發器）。
3. **導入**：逐表 `npx wrangler d1 execute amcm-db-restore-test --remote --file=backups/d1-amcm-20261105-preM1-<table>.sql`。
4. **重建 FTS**：執行 `INSERT INTO chunks_fts(chunks_fts) VALUES('rebuild');`
5. **斷言核對**（只讀 SQL）：
   - `SELECT COUNT(*) FROM guidelines` = 155；`chunks` = 3,617；`news` = 20；
   - 抽查 id14/15：`doc_number='002/2013-AMCM'/SUPERSENDED→026/2025`、`id15=026/2025-AMCM/IN_FORCE`；
   - 中文搜索 `雲端` 有命中且 (gid,page) 定位正確；
   - `SELECT COUNT(*) FROM chunks_fts` > 0。
6. **清理**：驗證通過後 `wrangler d1 delete amcm-db-restore-test`（副本庫，非生產）。
