依據：`M0_TEST_PLAN.md` §3。以下項目因無瀏覽器自動化權限未實機驗收，請人工在
**https://richapps.pages.dev/amcm/** 逐項點驗。預計 10–15 分鐘。
每項通過打 ✅，不通過請記錄現象與指引 ID。

## 準備

- [ ] 設備：桌面瀏覽器（Chrome/Edge）+ 手機（或 DevTools 手機模擬 375px 寬）
- [ ] 強制刷新一次（Ctrl+Shift+R）確保拿到 v3.1（頁腳應顯示「AMCM 指引通 v3.1」）

## T3.1 第一頁顯示

- [ ] 打開任一指引（建議抽 3 份：1 份銀行原生中文、1 份英文原件、1 份 OCR 標記文件）
- [ ] 進入詳情頁後**從第 1 頁開始**顯示，內容完整（封面/目錄可見），不是從中間頁開始
- [ ] 每頁之間有頁碼分隔線
- 通過 / 不通過（現象）：

## T3.2 連續閱讀（預設模式）

- [ ] 進入詳情頁預設即連續捲動模式，所有頁面連續渲染
- [ ] 長文（>50 頁）捲動流暢，無長時間白屏
- [ ] 刷新或返回後模式選擇被記憶
- 通過 / 不通過：

## T3.3 按頁閱讀

- [ ] 頂部切換「📄 按頁閱讀」，只顯示單頁
- [ ] 上一頁/下一頁按鈕翻頁正確，頁碼顯示同步
- [ ] 切回連續模式正常
- 通過 / 不通過：

## T3.5 搜索定位及高亮

- [ ] 大廳搜索中文關鍵詞（如「雲端」「流動性」），結果含指引名與頁碼
- [ ] 點擊命中 → 進入詳情頁並**自動捲動到命中頁**
- [ ] 命中文字**熒光黃高亮**，清除搜索後高亮消失
- [ ] 英文關鍵詞（如 liquidity）同樣定位+高亮
- 通過 / 不通過：

## T3.6 法規排版

- [ ] `第X條` 渲染為邊框標題卡；`第X章` 為更高一級章節卡
- [ ] `（一）`/`(1)` 子項有首行縮排
- [ ] 腳註上標 `[1]` 懸停顯示腳註內容；文末有腳註區
- [ ] 襯線字體（Noto Serif TC）生效，行距舒適
- [ ] OCR 頁頂部有黃色「請以官方 PDF 原文為準」提示（抽一份 OCR 文件驗證）
- 通過 / 不通過：

## T3.7 響應式佈局

- [ ] 手機寬度：篩選列可換行不溢出、正文無横向捲動
- [ ] 桌面寬度：正文欄寬合理（不超寬也不過窄）
- [ ] 頂部篩選、搜索框在手機上可用
- 通過 / 不通過：

## 附加體驗檢查（非阻塞）

- [ ] 列表/篩選加載時有 Skeleton 骨架屏
- [ ] BYOK 設定入口可用（填入 Key 後詳情頁可生成研讀儀表板）
- [ ] 「查看官方 PDF」連結可打開 AMCM 官網原件
- [ ] API 故障模擬（可跳過）：無異常崩潰白屏
